# 잠깐! 진짜? — 《연결할 용기》 동행 앱

빌드 없이 `index.html` 한 파일로 동작하는 정적 웹앱입니다. 정적 호스팅(GitHub Pages, Netlify 등)에 올리고 책 속지·표지에 QR 코드로 연결하면 됩니다.

## 구성
- **사고 디버깅** — 6단계(문제 고르기 → 정의 → 의식구조 → 다섯 질문 → 재해석 → 작은 실험). AI 없이 완전히 동작합니다.
- **순환 지도** — 개인/사회 층위 8단계 인터랙티브 지도 + 21개 주제 깊이 읽기 + 참고문헌.
- **책과 함께** — 밑줄 친 문장을 디버깅으로 가져가는 독서 노트.
- **내 기록** — 브라우저(localStorage)에만 저장. JSON/텍스트 내보내기·불러오기.

## 출판 전 채울 것 (`index.html` 상단 `CONFIG`)
- `author`, `publisher`, `purchaseUrl`
- `chapters`: 책 목차 `{title, question, issue}` — 비워 두면 자유 입력 모드
- `aiEndpoint`: 일반 웹에서 AI 보조를 켜려면 자체 서버 프록시 URL (API 키를 앱에 넣지 마세요). 비우면 AI 버튼은 숨겨집니다.

## 출간 전 확인 사항
- 참고문헌 서지(연도·판·쪽수)는 인쇄 전 원전 대조가 필요합니다.
- 책 본문 인용·장 구성은 저작권과 편집 방침에 맞게 확정하세요.
- 개인정보처리방침: 현재는 서버 수집이 없습니다. AI 엔드포인트를 연결하면 해당 단계 입력이 전송되므로 고지가 필요합니다.
