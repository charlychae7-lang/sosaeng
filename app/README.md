# 잠깐! 진짜? — 《연결할 용기》 동행 앱

빌드 없이 `index.html` 한 파일로 동작하는 정적 웹앱입니다. 정적 호스팅(GitHub Pages, Netlify 등)에 올리고 책 속지·표지에 QR 코드로 연결하면 됩니다.

## 책과의 대응
| 앱 | 책 |
|---|---|
| 사고 디버깅 · 빠르게(5단계) | 20장 「잠깐! 진짜?」 UX 5단계 (생각 꺼내기 → 잠깐! → 핵심 질문 → 생각의 틈 → 나의 작은 선택) |
| 사고 디버깅 · 깊게(6단계) | 1·2·3·12장 + 사고의 순환 지도의 확장 흐름 |
| 확신도·거리감 | 20장 KPI "생각과의 거리두기" (긍정화가 아님) |
| 순환 지도 | 1장(5단계 인지 순환), 10장(6단계 사슬), 12장(닫힌/열린 순환) |
| 책과 함께 | 프롤로그~에필로그 장별 질문·실험, 부록 용어집 |
| 미래 설계 | 19장 5단계 캔버스·30일 실험 카드, 에필로그 선언문 |

## 출판 전 확인 (`index.html` 상단 `CONFIG`, `CHAPTERS`)
- `purchaseUrl`: 도서 안내/구매 링크
- `aiEndpoint`: 일반 웹에서 AI 보조를 켜려면 자체 서버 프록시 URL (API 키를 앱에 넣지 마세요). 비우면 AI 버튼은 숨겨집니다.
- `CHAPTERS`: 장별 요약·질문은 책에서 요약해 옮겼습니다. 저자 확인 후 다듬어 주세요.
- 참고문헌(`REFS`): 책 부록 1과 사고의 순환 지도 문헌을 합쳤습니다. 인쇄 전 서지(연도·판·쪽수) 대조가 필요합니다.
- 개인정보: 현재는 서버 수집이 없습니다. AI 엔드포인트를 연결하면 해당 단계 입력이 전송되므로 고지가 필요합니다.
